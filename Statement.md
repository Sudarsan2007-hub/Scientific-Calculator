# Project Statement



## Project Title



** Calculator using Python **



## 1. Problem Statement



Doing math tasks one by one can take time especially when both simple math and more complex scientific math are needed. A simple calculator program can offer these functions through one menu-based application.



The goal of this project is to create a Python-based calculator that lets users do common math and some scientific math from the command line.



## 2. Scope of the Project



The project is for a command-line calculator. It takes input from the user does the chosen math and shows the result.



The calculator can do:



Addition



Subtraction



Multiplication



Division



Power



Root



Logarithm



Sine



Cosine



Tangent



Factorial



Percentage



The program also includes some checks for inputs.



## 3. Target Users



The project is, for:



Students learning Python



People who need math tasks



Newcomers who want to learn about menu-based programs and Python functions



## 4. High-Level Features



1. Menu-based calculator interface



2. Simple math functions



3. Scientific math functions



4. Code organized in functions



5. Basic error checking



6. Use it over and over until the user decides to stop



## 5. Input and Output



### Input



The user gives:



The choice of what math to do



One or two numbers based on the selected math



`Y` or `n` to keep using or stop the calculator



### Output



The program shows the result of the math or an error message when something is wrong.



## 6. Technology



The project uses Python 3. The built-in `math` module. It works in the command line or terminal.



## 7. Project Boundary



This version does not use a database, files, a graphical user interface or extra Python libraries. The project shows Python programming ideas through a scientific calculator.
